Büyüme ve İyileştirme Planı

Trafik, Gelir ve Kullanıcı Deneyimi Stratejisi

Oluşturulma: 31 Mart 2026

Site: yarinhava.com — ~48.000 statik sayfalık Türkiye hava durumu sitesi (Astro + Netlify + GitHub Actions)

Güçlü yanlar: SEO altyapısı (JSON-LD, FAQ schema, sitemap, dinamik meta taglar), 81 il + 1050+ ilçe kapsamı, 6 dönem varyasyonu

Eksikler: Analytics yok, AdSense kapalı, kullanıcı bağlılığı özellikleri eksik

Hedef: Organik trafik → reklam geliri → sürdürülebilir büyüme

A) HEMEN YAPILANLAR P0 — Bu Hafta

Kod değişikliği gerektirmez, admin panelinden yapılır:

1. Google Search Console Kaydı

  • Neden: Google siteyi indekslesin, sitemap'i tanısın. 48.000 sayfanın keşfi hızlansın.
  • Nasıl: search.google.com/search-console → domain ekle → doğrulama kodunu admin Routing > Google Search Console alanına yapıştır → sitemap submit et (sitemap-index.xml)

2. Yandex Webmaster Kaydı

  • Neden: Türkiye'de Yandex kullanımı var, ek trafik kaynağı
  • Nasıl: webmaster.yandex.com → domain ekle → kodu admin Routing > Yandex Webmaster'a gir

3. Bing Webmaster Kaydı

  • Neden: Bing + DuckDuckGo trafiği
  • Nasıl: bing.com/webmasters → Google import veya manuel ekle → kodu admin Routing > Bing Webmaster'a gir

4. Google Analytics 4 Kurulumu

  • Neden: Trafik takibi olmadan neyin işe yaradığını bilemezsiniz
  • Nasıl: analytics.google.com → GA4 property oluştur → Measurement ID'yi admin Site Settings > Google Analytics 4 ID'ye gir

5. Yandex Metrica Kurulumu

  • Neden: Heatmap, session recording, web visor (ücretsiz!) — GA'dan bile daha detaylı
  • Nasıl: metrica.yandex.com → counter oluştur → ID'yi admin Site Settings > Yandex Metrica ID'ye gir

6. AdSense Başvurusu

  • Neden: Para kazanma. 48.000 sayfa + hava durumu nişi = iyi RPM
  • Nasıl: adsense.google.com → başvur → onaylanınca publisher ID + slot ID'leri admin'e gir
  • Not: Onay 1-2 hafta sürebilir, hemen başvur
  • Dikkat: Mevcut AdSlot.astro sadece boş div render ediyor — gerçek AdSense kodu eklenmesi gerekecek
  • Başlangıç: Sayfa başı max 2-3 reklam. 11 slotun hepsini açma

6b. Build Sıklığını Artır (Günde 4x)

  • Neden: Hava verisi 12 saat eskiyebiliyor. Google'ın gördüğü değer bayat
  • Nasıl: Workflow'a 2 cron daha ekle (12:00 + 16:00 TR saati)
  • Maliyet: GitHub Actions free tier 2000dk/ay. 4 build × 15dk × 30gün = 1800dk → sınırın içinde

B) KISA VADELI KOD İYİLEŞTİRMELERİ P1 — 1-2 Hafta

7. Kullanıcı Konumu Otomatik Algılama (Geolocation)

  • Neden: Ziyaretçi siteye girdiğinde kendi şehrinin havasını görsün → bounce rate düşer
  • Nasıl: Browser Geolocation API → en yakın il/ilçe → banner göster (yönlendirme değil)
  • Dosyalar: src/pages/index.astro

8. Hava Kalitesi (AQI) Verisi Ekleme

  • Neden: Rakiplerden farklılaşma. Çoğu Türk hava sitesinde AQI yok. Yeni long-tail keywordler
  • Nasıl: Open-Meteo Air Quality API (ücretsiz) — PM2.5, PM10, NO2, O3, European AQI
  • SEO bonus: "İstanbul hava kalitesi", "Ankara PM2.5" gibi yeni aranabilir içerik
  • Dosyalar: src/lib/weather.ts, yeni AirQuality.astro component

9. Sosyal Paylaşım Butonları

  • Neden: Ücretsiz trafik. WhatsApp Türkiye'de çok yaygın
  • Nasıl: WhatsApp, Twitter/X, Facebook share linkleri (JS gerektirmez)
  • Örnek: whatsapp://send?text=İstanbul yarın 5°C! yarinhava.com/istanbul-hava-durumu

10. Favori Şehirler (localStorage)

  • Neden: Geri dönüş oranını artırır, kullanıcı deneyimini kişiselleştirir
  • Nasıl: localStorage'da şehir listesi → homepage'de "Favorilerim" bölümü
  • Maliyet: Sıfır (client-side)

11. Reklam Yerleşimi Optimizasyonu

  • Neden: Doğru yerleşim = 2-3x daha fazla gelir
  • En iyi pozisyonlar: Hava durumu kartının hemen altı, dönem tabları arası, saatlik tahmin sonrası
  • Dosyalar: src/components/AdSlot.astro, src/layouts/BaseLayout.astro

C) ORTA VADELI BÜYÜME P2 — 2-4 Hafta

12. Programmatik SEO — Mevsimsel İçerik Sayfaları

  • Neden: "İstanbul kış hava durumu", "Antalya yaz sıcaklıkları" — long-tail aramalar
  • Sayfalar: /istanbul-hava-durumu/yaz, /antalya-hava-durumu/kis vb.
  • SEO değeri: Yüksek — bu aramalar her yıl tekrarlanır (evergreen)

13. Polen ve Alerji Verisi

  • Neden: Niş özellik, rakiplerde yok. Alerji hastaları için değerli
  • Nasıl: Open-Meteo Pollen API (ücretsiz)
  • SEO bonus: "İstanbul polen tahmini", "çim poleni bugün" gibi keywordler

14. Haftalık Hava Durumu Özet E-postası

  • Neden: Geri dönüş trafiği, doğrudan kanal oluşturma
  • Nasıl: Buttondown veya Mailchimp free tier + footer'a kayıt formu

15. PWA Offline Desteği

  • Neden: Mobil kullanıcılar için app-benzeri deneyim
  • Nasıl: Service worker → son ziyaret edilen sayfaları cache

15b. Hava Uyarı Bannerları

  • Neden: "Yarın İstanbul'da şiddetli yağış!" → dikkat çeker, geri dönüş
  • Nasıl: Build-time'da aşırı koşulları bul (yağış>20mm, sıcaklık<-10, rüzgar>60km/h)
  • Yeni API gerekmez: Mevcut veriyle threshold kontrolü yeterli

16. Daha Zengin Yapısal Veri (Schema.org)

  • Neden: Google'da zengin snippet'lar → daha yüksek CTR
  • Eklenecekler: WeatherForecast schema, FAQ'ları 6-8 soruya çıkar

D) UZUN VADELI STRATEJİ P3 — 1+ Ay

17. Blog / İçerik Pazarlama

  • Neden: Bilgilendirici içerik = backlink + otorite + organik trafik
  • Konular: "Türkiye'de en sıcak iller", "Kışın tatil için en iyi yerler", "Hava durumu nasıl okunur"
  • SEO değeri: Çok yüksek — bilgi amaçlı aramalar

18. Şehir Karşılaştırma Aracı

  • Neden: Viral potansiyeli var, rakiplerde yok
  • URL: /karsilastir/istanbul-antalya

19. Hava Durumu Widget'ı (Embed)

  • Neden: Diğer siteler embed edince backlink gelir → SEO otoritesi artar

20. Tarihsel Hava Verisi Sayfaları

  • Neden: "İstanbul geçen yıl hava durumu" → rakiplerde yok, evergreen SEO
  • Nasıl: Open-Meteo Historical API (ücretsiz)

21. Türk Diasporası Genişlemesi

  • Neden: 6M+ Türk yurt dışında. "Berlin hava durumu" Türkçe arıyorlar
  • Rekabet: Düşük — Türk hava siteleri sadece Türkiye

22. Alternatif Gelir: Affiliate

  • Fırsatlar: Yağmurda şemsiye/yağmurluk, karda mont/kış lastiği, tatil bölgelerinde otel/uçak
  • Nasıl: Trendyol, Hepsiburada affiliate programları + hava durumuna göre bağlamsal öneriler
